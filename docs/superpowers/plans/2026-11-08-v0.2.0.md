# QuotaGlass v0.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v0.2.0: pill + two-pane panel in the Pace Band look, glass material and theme settings, 50/80/90% native warnings, fast burn and Best now, explicit account connection with CLI profiles, and Antigravity read from the running Antigravity app.

**Architecture:** Pure logic (identity, pace, warnings, parsers, path guards, window geometry) lives in `crates/core` or in pure functions in `src-tauri`, each with unit tests. The scheduler builds its provider list from settings instead of fixed indices. The UI is rebuilt in plain TypeScript on the existing `h()` DOM helper.

**Tech Stack:** Rust 1.90 workspace (`crates/core`, `src-tauri`), Tauri 2, `window-vibrancy` 0.8.1, `tauri-plugin-notification` 2 (new), TypeScript 5.9 + Vite 7, no UI framework.

**Spec:** `docs/superpowers/specs/2026-11-08-v0.2.0-design.md` (approved 2026-11-08). Product truth: `PRODUCT.md`.

- Windows commands: `~/.cargo/bin/cargo.exe`, `npm.cmd`; `tauri build` from a PowerShell script that adds `C:\Users\Adyr\.cargo\bin` to `$env:Path`.

- The word "unofficial" does not appear in the UI.
- Version `0.2.0` in `package.json`, `Cargo.toml` `[workspace.package]`, `src-tauri/tauri.conf.json`.
- Fast burn: `used% >= 1.5 × passed%` and `used% >= 20`. Warning levels: 50, 80, 90.
- Provider colours: Claude `#d97757`, Codex `#10a37f`, Antigravity `#4c8df6`.
- Tests: `~/.cargo/bin/cargo.exe test --workspace` and `npm.cmd run build` pass after every task. `cargo clippy --workspace -- -D warnings` and `cargo fmt --check` clean.

## Review Focus

1. **The Antigravity IDE closes or restarts mid-session** (new port, new CSRF token): the source returns `NotDetected` quietly, keeps no stale numbers on screen as live, and finds the new port on the next tick. Test: Task 5 `ports_change_between_calls_is_rediscovered`.
2. **A reset time in the past or a missing window length**: `passed_percent` clamps to 0–100 and returns `None` without `window_secs`, so fast burn never fires on bad data. Test: Task 2 `passed_percent_edges`.
3. **The pill sits near a monitor edge, or on a second monitor, when the panel opens**: the panel stays inside that monitor's work area (down when there is no room above, shifted left/right to fit). Test: Task 10 `panel_rect_fits_work_area`.
4. **A v0.1.0 `settings.json` with extra, missing or broken fields**: it migrates to v2 keeping window position and refresh interval; a broken file is kept as `settings.json.bad`. Test: Task 3 `v1_file_migrates`, `broken_file_kept`.
5. **A profile folder deleted outside QuotaGlass, or a remove that races a refresh**: the card shows "Profile missing" instead of an error loop; delete never leaves `%APPDATA%\QuotaGlass\profiles\`. Test: Task 9 `missing_profile_is_reported`, `guard_rejects_outside_paths`.
